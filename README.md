# CurlyBlue: Test Netcode

## How to Test
1. Open multiple `.exe` clients from the `Builds` folder.
2. Host a session in one instance, others join as clients.

## Tech Stack
- **Unity** (C#)
- **Netcode for GameObjects**
- **Cinemachine** (Camera System)

## Dependencies
- [Unity Netcode Docs](https://docs.unity3d.com/6000.0/Documentation/Manual/com.unity.netcode.gameobjects.html)
- [Starter Assets - Third Person](https://assetstore.unity.com/packages/essentials/starter-assets-thirdperson-updates-in-new-charactercontroller-pa-196526)
